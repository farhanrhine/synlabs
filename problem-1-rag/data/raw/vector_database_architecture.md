# Vector Database Architecture and Optimization Guide

## 1. Introduction to Vector Search
Vector databases index high-dimensional embeddings generated by deep learning models. Unlike traditional relational databases that query structured rows using B-Trees or exact keyword matching via inverted indexes, vector databases perform Approximate Nearest Neighbor (ANN) search across high-dimensional vector spaces.

## 2. Approximate Nearest Neighbor (ANN) Algorithms
The two dominant ANN algorithms in modern vector stores are:

### Hierarchical Navigable Small World (HNSW)
HNSW constructs a multi-layer graph where lower layers contain dense clusters of vectors and upper layers contain long-range skip connections. 
- **Query Complexity:** logarithmic search complexity O(log N).
- **Pros:** Excellent recall (>98%) and sub-millisecond retrieval latency.
- **Cons:** High memory overhead during indexing; requires holding graph links in RAM or memory-mapped files.

### Inverted File with Product Quantization (IVF-PQ)
IVF clusters the vector space into Voronoi cells using k-means. At query time, only vectors inside the nearest centroids are evaluated. Product Quantization compresses floating point vectors (e.g., 32-bit floats) into short 8-bit codes.
- **Pros:** Substantial RAM reduction (up to 90% footprint reduction).
- **Cons:** Loss of precision and reduced recall@k compared to uncompressed HNSW.

## 3. Distance Metrics
The choice of distance metric must strictly match the embedding model training objective:
- **Cosine Similarity:** Measures the angle between normalized vectors, ranging from -1 to 1. Invariant to vector magnitude.
- **Dot Product / Inner Product:** Ideal for unit-normalized embeddings where cosine similarity is mathematically equivalent to dot product, saving computation.
- **Euclidean Distance (L2):** Measures straight-line distance in Euclidean space.

## 4. Cost Analysis and Managed Database Overhead
Fully managed cloud vector databases charge continuous monthly fees for always-on compute instances or provisioned pod tiers:
- A standard managed cluster typically starts at $70 to $250 per month for 1M vectors, regardless of whether queries are actively running.
- Self-hosted or embedded vector databases (such as Qdrant embedded or self-hosted instances) store vectors in memory-mapped files (mmap) on local NVMe SSDs.
- Storing 1M 384-dimensional vectors with 16-bit float precision requires approximately 768 MB of raw storage, plus ~1.5 GB for HNSW graph indexes. A modern $15/month VPS with 4GB RAM can easily serve 1M vectors with p95 latency under 15ms.
